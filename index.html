00 — The mission

One industrial system.
Five layers.

This portfolio is one connected engineering project: control → telemetry → software → delivery → security. Each section solves the next part of the same problem.

PROJECT / REMOTE INDUSTRIAL PUMP STATION
01 · FIELDSensors · motor · pump

The machine creates the signal.

A PLC controls the pump, watches process values and exposes clear states. The physical layer is represented as an abstract industrial interface.

02 · REMOTERTU · Modbus · telemetry

03 · SOFTWAREPython · Linux · data

Lightweight services validate and transform telemetry. Linux provides a predictable runtime for the edge services.

04 · DELIVERYDocker · GitHub · CI/CD

05 · DEFENSEOT security · Kali

The system is tested before it is trusted.

Network boundaries, exposed services and industrial communication paths are reviewed from a defensive cybersecurity perspective.

01 — PLC / HMI / SCADA

The control layer.

The PLC is where the machine makes its decisions. The HMI keeps the operator in the loop: run state, feedback, alarms and the few numbers that actually matter.

Engineering logic

Safe sequence

Press Start and the PLC checks the interlocks first. If everything is healthy, the motor runs and its feedback comes back to the HMI. Stop, overload and alarm paths stay visible instead of being hidden in the logic.

04 — OT Security / Kali Linux

Test the system
before trusting it.

Security belongs inside the same story: discover assets, understand protocols, segment critical paths and correlate network behavior with process behavior.

SECURITY LAB / OT NETWORK / DEFENSIVE VIEW

Asset visibility

DISCOVERY

Map PLC, RTU, HMI and server roles before making assumptions about the network.

$ nmap --top-ports 100 --open → inventory

Protocol awareness

MODBUS / OT

Understand which services are operationally necessary and which paths should never be casually exposed.

$ tcpdump -ni eth0 → traffic visibility

Segmentation

DEFENSE

Separate control, telemetry, management and external services so one compromise does not become a system-wide failure.

PLC → RTU → SECURITY ZONE → MONITOR

Detection

OBSERVABILITY

Correlate logs, network behavior and process state to create useful alerts.

EVENT + TELEMETRY + LOG → ALERT
