راهنمای نسخه 1.3.0 پورتفولیوی محمد شکاری

تغییرات این نسخه:
- چهار تم قابل انتخاب با دایره‌های کوچک نورانی در نوار بالای سایت: زغالی اصلی، بادمجانی تیره، سفید و کلاسیک سرمه‌ای/طلایی.
- انتخاب تم در همان مرورگر ذخیره می‌شود و با بازدید دوباره باقی می‌ماند.
- نام «ربات ممدم» و متن دعوت به تعامل در کنار آیکون بالای صفحه، برای موبایل و دسکتاپ نمایش داده می‌شود.
- بخش «نمونه‌کارهای آینده» در انتهای سایت با سه کارت رزروشده برای PLC/HMI، RTU و Python اضافه شده است.
- شماره نسخه سایت به 1.3.0 و نسخه ربات به 1.3.1 افزایش یافته است.

آمار بازدید خصوصی — نیازمند یک مرحله راه‌اندازی:
آمار واقعی را نمی‌توان فقط با HTML و بدون حساب سرویس آمار فعال کرد. این نسخه جای اتصال Umami Cloud را دارد، اما شناسه وب‌سایت هنوز وارد نشده؛ بنابراین آمار هنوز فعال نیست.

مراحل ساده:
1. وارد https://cloud.umami.is/ شو و یک حساب بساز.
2. داخل پنل Umami، یک Website اضافه کن و آدرس GitHub Pages سایتت را وارد کن.
3. از تنظیمات Website، شناسه (Website ID) را کپی کن.
4. در فایل index.html عبارت REPLACE_WITH_YOUR_UMAMI_WEBSITE_ID را پیدا کن و فقط همان عبارت را با شناسه واقعی جایگزین کن.
5. فایل را در GitHub منتشر کن. از پنل Umami با ورود به حساب خودت می‌توانی بازدید روزانه، بازدیدکنندگان یکتا، صفحات پربازدید و منبع ورودی مثل Instagram را ببینی. کاربران سایت به داشبورد خصوصی تو دسترسی ندارند.
6. برای سنجش اینستاگرام، لینک بیو را با پارامتر UTM تنظیم کن؛ نمونه: https://YOUR-SITE-URL/?utm_source=instagram&utm_medium=social&utm_campaign=bio

نکته: تا وقتی Website ID واقعی وارد نشده، نباید انتظار آمار واقعی داشت. اگر شناسه را برای من بفرستی، می‌توانم آن را در فایل قرار دهم. شناسه عمومی وب‌سایت محرمانه نیست؛ رمز عبور حساب Umami را هرگز ارسال نکن.

فرم ایمیل:
فرم پیام همچنان از FormSubmit استفاده می‌کند. باید سایت از GitHub Pages باز شود و ممکن است ارسال نخست نیاز به تأیید ایمیل داشته باشد. پس از انتشار، ارسال آزمایشی انجام بده.

ویدئوها:
ZIP مبنا شامل فایل‌های MP4 نبود؛ اگر ویدئوها در سایت آنلاین فعلی وجود دارند، هنگام جایگزینی فایل‌ها پوشه ویدئوهای موجود را حذف نکن.
